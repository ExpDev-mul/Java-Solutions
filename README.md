# ☕ Java Solutions

A collection of Java solutions to complex algorithmic problems, focusing on recursion, optimization, and efficient time and space complexity.

## 📌 Features

- ✅ Clean, well-structured Java implementations
- 🔁 Recursive and iterative approaches
- ⏱️ Time & space complexity optimization
- 🧠 Covers classic and advanced problems

## 📂 Structure

Each solution is organized by topic or problem type. Comments and method names are provided for clarity and learning.

## 💻 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Java-Solutions.git
   cd Java-Solutions
   ```

2. Open the `.java` files in your preferred IDE (e.g., IntelliJ, VS Code) and run as needed.
